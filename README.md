# ponchi maker — ポンチ絵メーカー

四角と文字で、GUIのレイアウトをさっと伝えるブラウザ用エディター。

公開先： https://non-cinnamon.github.io/ponchi-maker/

## できること

- 四角と文字の追加・移動・サイズ変更（四隅と辺の8ハンドル）
- 文字入り四角の文字を常に中央に表示。サイズ変更時も文字サイズは維持
- 文字の改行と折り返し。文字だけの要素は文字編集時に枠を自動調整
- Shift＋クリックと範囲選択による複数選択、まとめて移動
- 左右上下・中央揃え、横と縦の隙間の均等配置
- 要素一覧から隠れた要素を選択、ドラッグやボタンで重なり順を変更
- Photoshopのレイヤーグループのようなグループ化・入れ子・折りたたみ（最大32階層）
- グループ単位の移動・サイズ変更・複製・削除・整列、グループ解除
- 一覧は1行26pxのコンパクトなツリー表示。グループ内へのドラッグ格納・最上位への移動
- 名前・座標・寸法・文字サイズ・色・枠線・角丸の編集
- 複製、削除、元に戻す・やり直す（最大100操作）
- Qt Designer `.ui` のImport / Export、独自JSONのImport / Export、PNG書き出し
- ブラウザへの自動保存、表示倍率変更、グリッド表示

## 使い方

左の「四角」「文字」から要素を追加します。ドラッグで移動、選択枠のハンドルでサイズを変更、ダブルクリックで文字を編集します。右の要素一覧は上ほど手前です。背後の要素は一覧から選択し、選択枠の線をドラッグするか数値欄で編集できます。

整列は選択した要素全体の外枠が基準です。均等配置は3個以上で利用でき、両端を固定して要素の間の隙間を均等にします。要素が収まりきらない場合は移動せず、両端を離すよう案内します。

作業領域の初期サイズは1200×800、設定可能範囲は幅320〜4096、高さ240〜4096です。要素は作業領域内に配置されます。初版はパソコンでの利用を想定しています。狭い画面では横スクロールが発生します。

## 保存

上部の操作は `Qt [Import] [Export]` と `JSON [Import] [Export]` に分かれています。JSONはグループを含む編集データ全体を保存する形式です。旧v1 JSONと以前の自動保存も読み込めます。

編集データはブラウザのlocalStorageに自動保存されます。ブラウザデータの削除や端末変更に備え、JSONファイルとして保存してください。ファイル読込は形式と値を検証し、最大2MB・1000要素です。読込と新規作成は元に戻せます。

PNGには作業領域のみを書き出し、選択枠やグリッドは含めません。図形の外にあふれた文字も表示されますが、作業領域の外は切り取られます。フォントの見た目は端末の環境に依存します。

外部サービス・外部フォント・解析ツール・APIは利用していません。アプリから編集データをサーバーに送信する処理はありません。GitHub Pages自体の通信・ログの扱いはGitHubの規約に従います。

## グループ

同じ親の要素を複数選択して「グループ化」（Ctrl・⌘＋G）。グループの中に別のグループを入れられます。グループ選択時は全体を移動・サイズ変更でき、文字サイズは維持します。子要素が24px未満になるサイズ変更は行いません。個別編集はアウトライナーから子を選択するか、キャンバスでAlt＋クリックします。

行の三角で展開・折りたたみ。行の上端・下端へのドラッグで同じ階層の前後を変更し、グループ行の中央へドラッグすると中へ入ります。一覧の下の「ここにドロップで最上位へ」でグループから出せます。「解除」（Ctrl・⌘＋Shift＋G）は子の位置を保って1階層上に戻します。最前面・最背面などの操作は同じ親の中で行います。

## Qt .ui

Qt 4.0形式のXMLを読み書きします。出力したファイルはQt DesignerやPySide / PyQtのuic・UIローダーで利用できます。

- 四角と文字は基本的にQLabelに変換。四角は枠線・背景色をスタイルシートで表します。
- グループはQWidgetに変換。子が横一列で互いに重ならない場合はH（QHBoxLayout）、縦一列ならV（QVBoxLayout）を自動判定して生成します。異なる大きさの要素も、直交方向の範囲が共通する場合に判定できます。
- 重なり、斜め、複数列などは自由配置とし、座標と前後関係を保存します。方向はグループのプロパティでH / V / 自由配置に指定し直せます。
- 入れ子のレイアウト、絶対座標、QMainWindow・QWidget等の階層、QLabel・QPushButton・QLineEdit等の一般的なウィジェットを簡略読込します。対応するQtクラスは再出力にも引き継ぎます。
- 外部.ui内のレイアウト管理された要素は、寸法情報がなければ利用可能な領域から位置を計算します。グリッド・フォーム配置は行列位置からの近似です。Qt本体のレイアウト計算と完全には一致しません。
- このツールはレイアウトのポンチ絵用です。シグナル接続、画像・リソース、アクション、全プロパティ、複数ページの切替、ウィジェットの動作は保持しません。未対応クラスはラベルに置き換えます。読込時に変換の注意点を表示します。
- 当ツールで出力した.uiには再読込用の管理名・種類などを動的プロパティとして付けます。完全な編集状態を残す用途にはJSONを併用してください。

形式の根拠：[Qt UIファイル形式](https://doc.qt.io/qt-6/designer-ui-file-format.html)、[Qt Designerのレイアウト](https://doc.qt.io/qt-6/designer-layouts.html)。

## 技術と開発

HTML / CSS / JavaScript（ES Modules）/ SVG / Pointer Events / localStorage / Canvas（PNG生成・文字幅計測）/ DOMParser（Qt XML読込）。実行時の外部ライブラリとビルド処理は不要です。

Node.jsがある環境では `npm start` で http://127.0.0.1:4173 を開けます。ES Modulesを利用するため、ファイルの直接ダブルクリックではなくHTTPサーバーで開いてください。

`npm install` の後、`npm test` で保存形式の検証、整列、前後関係、グループ、移動・サイズ変更、Qt入出力のテストを実行します。XMLパーサー `@xmldom/xmldom` はNode.jsでのテスト専用です。ブラウザでは標準DOMParserを使用します。

GitHub Pagesは `main` ブランチのルートを公開元に設定します。`.nojekyll` により静的ファイルをそのまま配信します。

## JSON形式（v2 / v1読込対応）

トップレベルは `format: "ponchi-maker"`, `version: 2`, `name`, `canvas: {width,height}`, `elements`。要素は `id`, `type`（`rect` / `text` / `group`）, `name`, `x`, `y`, `width`, `height`, `text`, `fontSize`, `color`, `fill`, `stroke`, `strokeWidth`, `radius` を持ちます。`parentId` が親グループを表します。座標は全要素で作業領域を基準とした絶対座標です。グループは `layout`（`auto` / `H` / `V` / `free`）を持ち、寸法は子の外枠から計算します。Qtから読み込んだ対応要素は `qtClass` を持つ場合があります。同じ親の要素は、配列の後ろほど手前です。色は6桁の16進数形式です。

| --- | --- |
| 四角 / 文字の追加 | R / T |
| 全選択 / 選択解除 | Ctrl・⌘＋A / Esc |
| 複製 / 削除 | Ctrl・⌘＋D / Delete |
| グループ化 / 解除 | Ctrl・⌘＋G / Ctrl・⌘＋Shift＋G |
| 1px移動 / 10px移動 | 矢印 / Shift＋矢印 |

| やり直す | Ctrl・⌘＋Shift＋Z または Ctrl・⌘＋Y |
| JSON保存 | Ctrl・⌘＋S |
