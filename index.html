移動・サイズ変更
ドラッグで移動。選択枠の四隅・辺でサイズ変更。文字の大きさは変わりません。
隠れた要素の編集
右の要素一覧から選択し、紫の選択枠の線をドラッグして移動。位置や大きさの数値入力でも編集できます。
グループ
同じ階層の要素を複数選択し「グループ化」（Ctrl・⌘＋G）。入れ子、まとめて移動・サイズ変更・複製ができます。「解除」はCtrl・⌘＋Shift＋G。一覧の三角で折りたたみ、グループ行の中央へドロップで格納、一覧下部へドロップで最上位へ移動できます。個別編集は一覧から選択、またはAlt＋クリック。
複数選択・整列
Shift＋クリック、または余白から範囲選択。整列は選択した全要素の外枠が基準です。
重なり順
要素一覧は上ほど手前。行の並べ替え、または矢印ボタンで同じ階層内の順番を変更できます。
Qt .ui
Qt Import / Exportから読込・書出。グループ内が横一列ならH、縦一列ならVに自動判定します。重なりや複数列は自由配置です。自動判定はプロパティから変更できます。四角・文字はQLabelに変換し、一般的なQtウィジェットも簡略読込できます。Qt側のサイズ調整で見た目が変わる場合があります。シグナル接続、画像、全ウィジェットの動作を再現するものではありません。
キーボード
R：四角 / T：文字 / Delete：削除 / 矢印：1px移動（Shiftで10px） / Ctrl・⌘＋D：複製 / Ctrl・⌘＋Z：元に戻す / Ctrl・⌘＋Shift＋Z：やり直す / Ctrl・⌘＋A：全選択 / Esc：選択解除
保存について
編集内容はこのブラウザに自動保存。JSONはグループ情報を含め完全に再編集するための形式です。旧JSONも読み込めます。共有や別端末への移動にもJSONを使ってください。サーバーへ編集内容を送信する機能はありません。
